# Анализ массива сообщений и логика правил

Массив: ~200 объявлений (после удаления пустых строк), смесь русского, туркменского (латиница и кириллица), транслита и опечаток. Много дублей (репосты по 2–4 раза).

## Закономерности

1. **Три типа авторов.** ~70 % — «еду и беру» (carrier), ~25 % — «есть кто едет? / хочу отправить» (sender), единичные — «нужно забрать/получить» (receiver). Остальное — просто анонс маршрута.
2. **Ядро объявления — маршрут + дата + глагол поездки + предмет** (документы/почта/посылки). По отдельности каждый признак шумный, вместе дают >90 % точности. Отсюда скоринг по сочетанию признаков, а не по ключевому слову.
3. **Роль различают грамматика и порядок слов**, а не лексика:
   - «алып гидип билян», «могу забрать», «заберу» → берёт (offer);
   - «гидян бармы / йокмы», «кто летит?», «гидян бар болса хабарлашайын» → ищет попутчика (request);
   - «угратмалы», «хочу отправить», «…ugratjaktym» → хочет отправить (request);
   - но «угратжак бар болса», «если хотите отправить» → это предлагает *едущий* (offer);
   - 1-е лицо («хабарлашайын», «язайын») → пишущий сам хочет связаться → request; 2-е лицо («хабарлашын», «пишите») нейтрально.
   - «нужно/надо забрать», «алдырмалы» → receiver.
4. **Города:** один город — до 8 написаний (Ашхабад/Ашгабат/Aşgabat/Asgabat/Ashhabad/ASG/Ашх), падежные окончания (-dan/-den, -a/-e/-na/-ne, русские -а/-у/-е), смешение кириллицы с туркменскими суффиксами («Питерден», «Ашгабада», «Дашагуздан»), опечатки («lebaba», «Красснаводск», «istabul»).
5. **Даты:** `07.10.2025`, `25.10.25.`, `4.10`, `12 11 2025`, «14 oktyabrda», «октябрын 3 на», «20ого июля», «2-3 октября», «шу айын 22», «31не», «8 10 piter…», а также относительные «ертир», «завтра», «якында», «на днях».
6. **Направление** определяется порядком городов в цепочке (первый не-ТМ → дальше ТМ = в Туркменистан; первый ТМ → дальше не-ТМ = из), суффиксами (-dan/-a) и предлогами (из/в/до).
7. **Шум:** машины/попутчики по России без Туркменистана (отсекается обязательным «Туркменистан-гейтом»), имя Мария ≈ город Мары (Mary — слабый алиас), реклама билетов/карго/виз/вакансий (отрицательные правила).

## Как достигается мало ложных срабатываний

- **Гейт Туркменистана:** без города/страны ТМ (или слабого признака + явного намерения) сообщение получает 0 баллов.
- **Слабые алиасы** (`дз`, `ag`, `asg`, `mary`, `balkan`, `dostluk`, `+993`) работают только вместе с глаголом поездки/намерением; нечёткие совпадения по опечаткам считаются слабыми.
- **Отрицательные правила** (−20…−35) и «жёсткие» исключения (казино и т. п.).
- **Устаревшая дата** (раньше чем сегодня−2 дня) — штраф −20.
- **Дубликаты:** точный хэш скелета, отпечаток «телефон/отправитель + маршрут + дата», simhash (расстояние ≤4).

## Скоринг (rules/scoring.json)

| Признак | Баллы |
|---|---|
| Туркменистан/город ТМ (сильный) | +20 (слабый +8) |
| Маршрут из ≥2 пунктов | +15 |
| Дата: точная / только число / относительная | +15 / +10 / +8 |
| Глагол поездки | +15 |
| Намерение (взять / отправить / получить), макс. | +30 |
| Предмет (документы/почта) | +10 |
| Контакт | +5 |
| Отрицательные правила | −20…−35 (кап −60) |

Пороги: **≥50 — уведомление** (меняется в боте), **≥75 — «высокий»**, **25–49 — сохраняется без уведомления** (для разбора и тонкой настройки).
