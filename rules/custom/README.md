# Пользовательские словари

Положите сюда файлы `keywords.*.json`, `cities.*.json`, `lexicons.*.json`, `scoring.*.json` — они
подмешиваются к основным (списки дополняются, одинаковые `id` правил/городов переопределяются).
Код менять не нужно: перезапустите контейнеры (или дождитесь автоперезагрузки в userbot).
Проверка слова: `python -m app.tools.skeleton "ваш текст"`.
